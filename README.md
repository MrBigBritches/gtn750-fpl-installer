# GTN750 Flightplan Installer
Drag and drop utility to move flightplans into the correct location for the [GTN750 by PMS50](https://pms50.com/msfs/).

## Installation
Download the latest release and unzip into a convenient location.

## Usage
Drag a flightplan file with the `.flp` extension onto the executable.

### Limitations
- Standard location of MSFS2024 UserCfg.opt file: `%LOCALAPPDATA%/Packages`.
- Default naming of the GTN750 folder from PMS50: `pms50-instrument-gtn750`.
