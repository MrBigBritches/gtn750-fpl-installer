# GTN750 Flightplan Installer
Drag and drop utility to move flightplans into the correct location for the [GTN750 by PMS50](https://pms50.com/msfs/).

## Installation
Download the latest release and unzip the executable to a convenient location.

## Usage
Drag a flightplan file with the `.pln` extension onto the executable.

### Limitations
- Microsoft Flight Simulator 2024
- Standard location UserCfg.opt file: `%LOCALAPPDATA%/Packages/Microsoft.Limitless_8wekyb3d8bbwe/LocalCache`.
- Default naming of the GTN750 folder from PMS50: `pms50-instrument-gtn750`.
